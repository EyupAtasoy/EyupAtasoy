# Eyup Enes Atasoy

AI engineer in Istanbul.

Most of what I build is in maritime. My main project is a multi-agent
assistant on LangGraph that reads shipping emails, pulls out the fields
that matter (ports, cargo, dates), checks them against reference data
and matches cargoes to vessels. It is private, so I publish the parts
I can share separately.

The part I care about most is what happens after the LLM answers:
checking the output against something real, measuring it on a labelled
set, and returning "unknown" when the system is not sure instead of
guessing.

Public code: [llm-grounding-kit](https://github.com/EyupAtasoy/llm-grounding-kit),
the validation layer from that project, rewritten with synthetic data
and a small benchmark.
